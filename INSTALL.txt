FANTASY MPL — ORDERED PROFESSIONAL DRAFT PIPELINE

A. DATABASE FIRST
1. Open Supabase Dashboard > SQL Editor.
2. Run:
   supabase/migrations/020_ordered_draft_import_pipeline.sql
3. Expected:
   ordered_import_ready: true
   metric_rebuild_ready: true

B. APPLICATION FILES
1. Copy the CONTENTS of this folder into the repository root.
2. Do not copy the outer fantasy-mpl-ordered-draft-pipeline folder.
3. Replace matching files.

C. COMMIT
  Add verified ordered professional draft importer

D. USE
Admin Console > Draft Intelligence > Ordered Professional Draft

Required for every game:
- approved source
- patch
- source match key
- game number
- played-at timestamp
- blue and red team
- winner side
- exact source game URL
- all 20 ordered actions

The importer rejects incomplete sequences, incorrect sides/phases, unknown heroes,
duplicate heroes, unknown teams, future dates and unapproved sources.

After a successful import PostgreSQL rebuilds, for that source/patch/region:
- games analyzed
- hero picks, bans, wins and calculated rates
- ally-pair synergy evidence (minimum 3 samples)
- enemy matchup evidence (minimum 3 samples)

The public model remains gated until its configured minimum sample is reached.
