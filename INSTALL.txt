FANTASY MPL — 24-HOUR PREDICTION WINDOWS

A. DATABASE FIRST
1. Open Supabase Dashboard > SQL Editor.
2. Open and run:
   supabase/migrations/017_prediction_windows.sql
3. Expected result columns:
   match_window_ready: true
   mvp_window_ready: true
   synchronized_matches: the number of scheduled match records

This migration does not delete predictions or accounts.
It synchronizes match lock deadlines to scheduled match times and weekly MVP
lock deadlines to the first non-cancelled match in each regional week.

B. APPLICATION FILES
1. Copy the CONTENTS of this folder into the repository root.
2. Do not copy the outer fantasy-mpl-prediction-windows folder.
3. Allow Windows to replace app/page.tsx and app/layout.tsx.

C. COMMIT
Commit message:
  Add server-enforced 24-hour prediction windows

D. EXPECTED UI
Before opening: PREDICTIONS OPEN IN / MVP VOTING OPEN IN
During window: PREDICTIONS LOCK IN / MVP VOTING LOCK IN
At deadline: PREDICTIONS LOCKED / MVP VOTING LOCKED

All countdowns update every second. PostgreSQL RLS and validation triggers reject
writes before opening and at or after the deadline.
