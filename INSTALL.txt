FANTASY MPL — CONTROLLED CLOSED-BETA ACTIVITY RESET

IMPORTANT
- Running Migration 018 only installs guarded functions. It deletes nothing.
- The reset itself is irreversible unless you have a database backup.
- Accounts, profiles, avatars, memberships, fixtures, teams, players and
  configuration are preserved.

A. BEFORE RESET
1. Download your account data from My Profile > Download My Data.
2. Confirm your main account is still super_admin.
3. If available on your Supabase plan, create/confirm a database backup.

B. INSTALL THE GUARDED RESET
Run in Supabase SQL Editor:
  supabase/migrations/018_controlled_beta_activity_reset.sql

Expected:
  preview_ready: true
  reset_ready: true

C. SAFE PREVIEW — DELETES NOTHING
Run:
  select public.preview_beta_activity_reset();

Review the will_delete_counts and will_preserve arrays.

D. EXECUTE THE RESET
Only after reviewing the preview, run exactly:
  select public.run_beta_activity_reset('RESET FANTASY MPL BETA ACTIVITY');

Expected:
  reset_complete: true
  after counts: all zero
  preserved_accounts: greater than zero
  preserved_profiles: greater than zero
  preserved_fixtures: greater than zero
  preserved_players: greater than zero

E. APPLICATION FILES
Copy the CONTENTS of this folder into the repository root.
Do not copy the outer fantasy-mpl-controlled-beta-reset folder.
The app change clears stale browser prediction selections when cloud rows were reset.

F. COMMIT
  Add guarded closed-beta activity reset
