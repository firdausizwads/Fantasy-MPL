FANTASY MPL — OBSERVABILITY AND SAFE LOAD TESTING

A. APPLICATION FILES
1. Copy the CONTENTS of this folder into the repository root.
2. Do not copy the outer fantasy-mpl-observability-load-test folder.
3. Replace package.json and matching files.
4. No npm dependency or Supabase migration is required.

B. COMMIT
  Add production health checks and safe regional load tests

C. VERIFY AFTER DEPLOYMENT
Open:
  https://fantasy-mpl-phi.vercel.app/api/health
Expected:
  status: ok
  database: reachable
  MY, ID and PH: status ok

D. GITHUB SMOKE
GitHub > Actions > Production smoke > Run workflow
The same smoke check also runs every 6 hours.

E. LOAD TEST — PREVIEW ONLY
1. Create or use a Vercel Preview deployment.
2. Install k6 on Windows:
   winget install k6.k6
3. Reopen PowerShell.
4. In the repository folder:
   $env:BASE_URL="https://YOUR-PREVIEW-DEPLOYMENT.vercel.app"
   npm run load:regional

The script blocks the production URL unless an explicit override is provided.
Do not override that protection during closed beta.
