FANTASY MPL — REGIONAL SCALING PHASE 2

2. Run:
   supabase/migrations/022_regional_operations_and_leaderboard_snapshots.sql
3. Expected:
   feature_flags_ready: true
   snapshots_ready: true
   refresh_ready: true

B. APPLICATION FILES
1. Copy the CONTENTS of this folder into the repository root.
2. Do not copy the outer fantasy-mpl-regional-scaling-phase2 folder.
3. Replace matching files.

C. COMMIT
  Add regional operations and leaderboard snapshots

D. VERIFY
1. Sign in as super-admin.
2. Open Admin Console > Regional operations.
3. Confirm all five regional features show OPEN.
4. Confirm the screen identifies only the currently active region.
5. Click REFRESH OVERALL. With no score data, 0 rows is correct.

E. IMPORTANT BEHAVIOR
- A paused feature affects only MY, ID or PH — never all three.
- Database prediction/MVP write protection is immediate.
- Public pause banners are CDN-cached for up to 15 seconds.
- Same prediction row cannot be resubmitted more than once every 3 seconds.
- Batch submissions across different matches remain valid.
- Scoring now rebuilds overall and weekly leaderboard snapshots automatically.
- Public leaderboards read snapshots instead of aggregating the full ledger.
