FANTASY MPL — PANDASCORE FIXTURE SYNCHRONIZATION

PREREQUISITES ALREADY COMPLETED
- PANDASCORE_API_TOKEN saved in Vercel Production
- PANDASCORE_SYNC_SECRET saved in Vercel Production
- CRON_SECRET saved in Vercel Production

A. DATABASE FIRST
1. Open Supabase Dashboard > SQL Editor.
2. Run:
   supabase/migrations/024_pandascore_fixture_sync.sql
3. Expected:
   ingestion_ready: true
   apply_ready: true
   review_ready: true

B. APPLICATION FILES
1. Copy the CONTENTS of this folder into the repository root.
2. Do not copy the outer fantasy-mpl-pandascore-fixture-sync folder.
3. Replace matching files.
4. Commit:
   Add PandaScore fixture synchronization and review queue
5. Push main and wait for Vercel Production to become Ready.

C. INITIALIZE AND SYNC
1. Sign in as super-admin.
2. Open Admin Console > Fixture sync.
3. Select SYNC NOW.
   The server securely stores only a SHA-256 hash of PANDASCORE_SYNC_SECRET in Supabase.
4. Review team mappings. Unknown acronyms are never guessed.
5. Map every unresolved PandaScore team to a verified regional team.
6. Review staged fixtures, dates, week numbers, statuses and scores.
7. Select APPLY READY only after the mappings are correct.
8. Repeat for MY, ID and PH.

D. RESULT SAFETY
- Finished scores enter matches as unverified.
- Open Admin Console > Matches & results.
- Verify the series score before running scoring.
- Canceled records without a scheduled time are skipped.
- Existing matching fixtures are linked within a 12-hour time tolerance instead of duplicated.

E. AUTOMATION
- Vercel cron runs daily at 02:15 UTC.
- Each run makes three PandaScore list requests: MY, ID and PH.
- Manual SYNC NOW remains available after reschedules or match completion.
