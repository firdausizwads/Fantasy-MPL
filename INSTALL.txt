FANTASY MPL — DRAFT INTELLIGENCE FOUNDATION

A. DATABASE FIRST
1. Open Supabase Dashboard > SQL Editor.
2. Run:
   supabase/migrations/019_draft_intelligence_foundation.sql
3. Expected:
   status_ready: true
   recommendations_ready: true
   import_ready: true

B. APPLICATION FILES
1. Copy the CONTENTS of this folder into the repository root.
2. Do not copy the outer fantasy-mpl-draft-intelligence-foundation folder.
3. Allow Windows to replace matching files.

C. DEPLOY
Commit message:
  Add governed Live Draft intelligence foundation

D. FIRST ADMIN CHECK
1. Sign in with the super-admin account.
2. Open Admin Console > Draft intelligence.
3. Confirm:
   PUBLIC MODEL: INACTIVE
   APPROVED SOURCES: 0
   VERIFIED GAMES: 0
4. Open /live-draft and confirm the Model panel remains DATA GATED.

E. SOURCE SAFETY
- Register candidate sources as PENDING first.
- Do not select COMMERCIAL USE CONFIRMED or PRIMARY MODEL SOURCE until rights
  and terms are documented.
- Never put an API key in NEXT_PUBLIC_* variables.
- Do not scrape normal website HTML.

F. METRICS IMPORT
CSV format:
  hero,games,picks,bans,wins

Rates are calculated by PostgreSQL. Unknown heroes, negative values and impossible
counts are rejected. Recommendations remain disabled until an approved primary
source, active patch, active model and minimum regional sample all exist.
